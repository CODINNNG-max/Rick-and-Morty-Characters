# Rick-and-Morty-Characters
A locally run, command-line Python project that uses the Rick and Morty REST API to search for characters and retrieve information. Users can filter searches by character status and species, then explore individual character details.

Features

- Search characters by name
- Filter by status and species
- Display matching character results
- Explore individual character information
- Handle connection errors and invalid input
- Parse JSON API responses

How to Run

Install the required dependency:

"pip install requests"

An internet connection is required to access the API.

Concepts Demonstrated

- REST API integration
- HTTP requests
- JSON parsing
- Dictionaries and lists
- Exception handling
- Input validation

Technologies: Python 3, Requests, Rick and Morty API
